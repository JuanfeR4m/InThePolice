# Low Poly Amusement Park Pack (Free)
by reodesuxz

24 low-poly amusement park rides, game stalls and park props for fairground, theme park and tycoon games.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Rides_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 4824 triangles for all 24 models (48-788 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
